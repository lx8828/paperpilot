## 三、⚠️ 边界（必须随结论一起看）

1. **本轮的"接地"列口径偏严**（未对齐）：`GROUND_SYS` 第一版问的是"证据是否**足以支持**"，
   而主判官 `SYS_SET` 问的是"该论文**是否做了**" → **门槛不同（充分性 vs 存在性）**，
   会把接地率人为压低（实测 `0/12`、`2/12`）。
   → **已改成同口径**（"该论文是否自己做了这件事"）并保留双判官 AND + 不给 `why`；
   **本轮数字尚未用新口径重跑** → `0.525` 应视为**下界**。
2. 与 dev 侧 0.886 / 0.955 的对比**仍不成立**：`gold_final3` 是**用 dev 协议标的** →
   dev 侧同源自证偏高、生产侧异源偏低（见 `R2_PROD_K_20261001.md` §2）。
3. 生产候选 = 全部 50 篇（`--topk 0`），非 top-k；k 曲线已给出，按成本选。
4. 单次运行。缓存已消掉 `decompose` 的漂移，但**判官（LLM）本身仍有非确定性**。
5. `2-efficiency`(gold 2)、`2-error_analysis`(gold 3)、`1-annotation_cost`(gold 4) 等
   **极小样本**对均值拉扯大（接地样本 0/5 能把该 facet 的通过率打到 0）。
