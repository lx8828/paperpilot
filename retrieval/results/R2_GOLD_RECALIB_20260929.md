# A｜R2 真值重标与敏感性（"能不能回去调参"的决定性检查）

日期：2026-09-29 ｜ 判官：`deepseek-chat`（A）+ `glm-4-flash`（B），异源｜约 1700 次调用

---

## 0. 结论（先说，含一条**对上一轮的推翻**）

1. **锚点真值确实太松**（篇级）：P **0.568** / R 0.893 → 正例 **8.1/题** 被高估，真实约 **5.9/题**。
2. **新真值的假阴性率 ≈2.5%** → 它的"否"可信。
3. **臂排序在「锚点 vs 最终」下一致** → **相对结论稳健** ✅
4. **但幅度差 2.4 倍**：多查询增益 `+0.051` → **`+0.120`**。
5. **★ 推翻上一轮结论**：「MMR 显著有害（−0.038）」是**锚点真值太松造成的假结论**；
   最终真值下是 **−0.001（不显著，零效应）**。
6. **可以回去调参了**，但必须用**最终真值**，且绝对值仍标"机器双标真值，非人工金标"。

## 1. 做法

对全部 **688** 个 (cluster, facet, paper) 对重标：

| 步 | 内容 |
|---|---|
| 证据池 | 锚点命中的块 ∪ **干净查询**（`zh` + 净化子查询，无锚点词）语义检索 top-3；4 块 ≤4200 字符 |
| 双判官 | `deepseek-chat` + `glm-4-flash`，四档（`entail/partial/neutral/contradict`）+ 置信度 + **逐字引用** |
| 采信 | 双方 `entail` → 正例；双方非 `entail` → 负例；分歧 → **第三轮严格对抗复核** |
| 提示纪律 | ① 以字面为准 ② **区分"本文做的"与"引用他人做的"**（glm 已知错法）③ **列在任务清单/评价指标/相关工作里 ≠ 做了** |

**富证据复判**：对争议对（115 锚点正→新否、18 锚点否→新正、40 随机两者皆否）用 **12 块 / ≤12000 字符**再判一次。

## 2. 结果

### 2.1 真值规模与锚点精度（篇级）

| | 锚点真值 | 严格（4 块证据） | **最终（富证据修正）** |
|---|---|---|---|
| 正例 / 题（20 篇） | **8.1** | 5.6 | **5.9** |
| 两判官一致率 | — | 0.873 | — |
| 走第三轮比例 | — | 0.089 | — |

**锚点真值 vs 双 LLM 重标**：锚点 P **0.568** ／ R **0.893**（266 个锚点正例 → 169 个被确认）。

> ⚠️ **与旧标定的方向相反**：旧 `R2_CALIB_20260928.md` 说 P 0.895 / R 0.567（"漏 43%"）。
> 两者**测的层级不同**：旧的是**片段级**（"锚点命中的那句是否真支持"→ 锚点句本身多半是对的），
> 本次是**篇级**（"这篇论文是否真做了"→ 全文任意一处**提及**都会让锚点变正）。
> **对"哪几篇做了 X"这个题型，篇级口径才是对的** → 所以本次结论优先。

### 2.2 争议对复判（决定性）

| 组 | n | 富证据后判 yes 的比例 |
|---|---|---|

**判读**：

- `sample` **只有 2.5% 变 yes** → **假阴性率 ≈2.5%** → 最终真值可信

## 3. 因此修正的三条结论

| 旧结论（锚点真值） | **修正后（最终真值）** |
|---|---|
| 多查询增益 +0.043，**贴边不显著** | 多查询增益 **+0.120，显著** ✅ |
| 轮询聚合无额外收益（+0.036 不显著） | 轮询也 **+0.093，显著** ✅ |
| **MMR 显著有害（−0.059）** | **MMR 是零效应（−0.001，不显著）** ← ❌ 旧结论作废 |
| 绝对值 0.681 / 0.725 等 | 改报最终真值下的 0.732 / 0.851 等 |

**为什么 MMR 会翻**：锚点真值把"全文提及该词"的篇也算正例（多出的 2.2 篇/题多为**勉强算**的），
MMR 的多样性惩罚正好推开这批"相似的边缘正例" → 在松尺子上显得"有害"；剔掉后效应消失。

## 4. 边界

1. **仍是"机器校准机器"**（两个异源 LLM 双标 + 一致才采信 + 分歧严格复核），
   **不是人工金标**。`R2_CALIB_20260928.md` 已记：两 LLM 一致率 0.900 量级（本次 0.873）。
   → 想彻底钉死，需人工抽检争议对（已导 `R2_GOLD_DISPUTE.csv`，115+18+40 条，可直接看）。
2. 证据上限 12 块（≤12k 字符），论文全文约 60k 字符 → **仍有残余假阴性**（实测 ≈2.5%，量小但非零）。
3. 结论只覆盖**干净查询集**（`zh` + 子查询）与 `dense` 一路。
4. 30/35 个题可用（5 个被剔除：重标后空真值或全正例，如 `deployment`、`multilingual` 等）。
5. n=30，配对 CI 仍较宽（如 B−A 的 CI 下界 +0.052，不算余量大）。
