# map / 分组枚举 / 逐候选判定（1m 档）：**治好了"少列"，但没治好"列错"**

日期：2026-09-29 ｜ 基准：LoFT RAG / QAMPARI / `1m` 档（100 题）｜ reader：`deepseek-chat`（no-think）
输入：重排后的 top-20（`rerank_top40.json` 的前 20）｜ 调用 3,993 次 / 404s / ¥≈2.5

---

## 0. 结论

1. **分解（map）确实治好了"系统性少列"**：`coverage` **0.5077 → 0.674~0.686（+17pt）**，
   平均预测数 **3.75 → 4.6~5.5**（gold **5.02**）→ 之前"模型提前收手"的诊断**被证实并修好了**。
2. **但 `subspan_em` 只从 0.390 → 0.440（+5pt）** —— 因为**上限被 coverage 卡住**（0.686）；
   多列出来的部分**很多是错的**（`em` 仍只有 0.14~0.25）。
3. **★ 逐候选 LLM 判定是【负收益】**：`0.440 → 0.330`、`coverage 0.686 → 0.622`，
   且只压掉 `7.0 → 5.5` 条 → **它把正确答案也一起删掉了**。与直觉相反。
4. **`grp10`（10 篇一组，**2 次调用/题**）是最佳操作点**：`em` **0.190 → 0.250（+0.06）**、
   `subspan` 持平、预测数 **4.63（最接近 gold 5.02）** → **几乎免费的正收益**。

**gold 平均答案数 = 5.02** ｜ gold 段落均被重排进 top-20

## 2. 三个读数

### 2.1 分解**确实**治好了少列（这是本次最重要的正面结果）

| | `single` | 分解各臂 |
|---|---|---|
| `coverage` | 0.5077 | **0.674 ~ 0.686**（**+17pt**） |
| 平均预测数 | 3.75 | **4.63 ~ 7.02**（gold 5.02） |

→ 「1m 档下模型一次看 20 篇会提前收手」的**诊断成立**，且**拆开就能修**。

### 2.2 但 `subspan_em` 被 **coverage 上限**卡住

`subspan_em` 要求**每个 gold 都被匹配上**（全有或全无）→ 其期望上限 ≈ `coverage`。
`coverage` 只到 0.686 → **即使一条不列错，`subspan_em` 也上不去**。
多列出来的 4.6~7.0 条里，错的占比不低 → `em` 停在 0.14~0.25。

### 2.3 ★ 逐候选 LLM 判定：**负收益**（重要负面结果）

| 从 → 到 | `subspan_em` | `coverage` | 预测数 |
|---|---|---|---|
| `passage_union` → `passage_verified` | 0.440 → **0.330** | 0.686 → **0.622** | 7.02 → 5.50 |

→ **它删掉的正确答案（coverage −6.4pt）多于它删掉的噪声（仅 −1.5 条）**。
→ 说明"让 LLM 看一句出处句就裁决候选"**判不准**（与之前 K2 线下"相似度阈值不可迁移"是同一类困难）。

## 3. 推荐操作点

| 场景 | 选哪个 | 理由 |
|---|---|---|
| **要最省且稳赚** | **`grp10`**（2 次调用/题） | `em` +0.06、预测数最接近 gold、`subspan` 持平 → **几乎免费** |
| **要最高覆盖/`subspan`** | **`passage_union`**（20 次/题） | `subspan` 0.440（+0.05）、`coverage` 0.686（+0.18），代价 20× 调用 |
| **不要用** | `passage_verified` | 负收益（见 §2.3） |
| **不要用** | `grp3` | 比 `grp5`/`grp10` 都差，且更贵 |

## 3.5 ★ 多列出来的条目**大多不是错答案，是"同一实体的不同写法"**（零 LLM 诊断）

把匹配口径从「规范化后**完全相等**」放宽为「**互为子串**」（= 官方 `subspan_em` 用的匹配规则）：

| 臂 | strict coverage | **loose coverage** | Δ | strict P | loose P |
|---|---|---|---|---|---|
| **`passage_union`** | 0.679 | **0.775** | **+0.096** | 0.570 | 0.639 |
| `grp10` | 0.627 | **0.693** | +0.066 | 0.644 | 0.717 |
| `passage_verified` | 0.597 | 0.669 | +0.072 | 0.599 | 0.661 |

**样例（strict 判错、loose 判对）**：

| 预测 | gold | 差异性质 |
|---|---|---|
| `2018 Kentucky Bank Tennis Championships` | `… – mens singles` | **缺限定词** |
| `GL-812 HY` | `gourdouleseurre gl812 hy` | **音译/拼写差异** |
| `Carousel (A Dance)` | `carousel` | **多了限定词** |
| `The Elmendorf Christian Community (or … Colony)` | `elmendorf christian community` | **括号补充** |

→ **`passage_union` 的 coverage 里有 +9.6pt 是"写法差异"而非"答案错"**
→ **归并 / 实体级匹配是下一个明确的收益点**，且它**不需要动召回**（纯后处理）。

⚠️ 但**不是纯字符串规则能解决**：要处理「缺限定词」「跨语言音译」→ 需要**实体级归并**
（可用 1 次 LLM 调用/题做归并，成本 100 calls，**远低于**逐候选判定的 700 calls）。

## 4. ⚠️ 一个必须记录的方法学教训

**冒烟（8 题）里 `grp5` 是"赢家"（subspan 0.500 / em 0.375），全量 100 题复现后掉到 0.370 / 0.210。**
→ **与之前多次踩的同一个坑一致**（8 个样本下结论 → 被更大样本推翻）。
→ 结论：**任何"某臂领先"的观察，样本 < 50 题不作数。**
