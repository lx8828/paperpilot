## 0. 结论（先说结果）

**结论：不引入新模型的重排/校正手段，没有一个能超过现状。**

依据（口径自校验）：本脚本的 `vec` 行**完全复现** `CHUNK_METRICS_20260910.md` B3/B4 的
`0.292 / 0.880 / 0.968 / 0.988 / 0.481 / 0.744`；`hyb0.50` 行**完全复现**现行线上的
`0.324 / 0.908 / 0.984 / 0.992 / 0.512` —— 说明取数与生产一致，否定结论不是脚本自身偏差。

| 手段 | 相对现状 hyb0.50（NDCG 0.612 / AUC 0.770） | 判读 |
|---|---|---|
| **各向异性校正**（mean / pc1 / pc2 / pc3） | NDCG 0.586–0.598、AUC 0.737–0.753 **全部下降** | ❌ 预测被自己的数据**证否**（原假设"0.605 高基线 → 校正有效"不成立） |
| **完整白化**（white） | NDCG **0.540**、AUC 0.701、gold@1 0.204 | ❌ 明显更差（放大噪声方向） |
| **节级配额**（cap） | NDCG 0.594、R@8 0.864↓、R@12 0.952↓ | ❌ 略差（**注**：本实现是全表保序配额，与生产 `_cap_select`（仅在 top_k 内配额）不同，不能据此推翻代码注释里的离线结论） |
| **MMR 去冗余** | NDCG 0.382、AUC 0.447 | ❌ 灾难性（把相关块一起压掉） |
| **RRF 权重调向向量**（α 0.5→0.7） | gold@1 0.324→0.336、NDCG 0.612→**0.617**，但 R@12 0.984→0.972 | ⚠️ 微增 top-1，代价是 R@12 下降；差 3 题，属噪声量级 |

**剩下的唯一未证否路线 = 真 cross-encoder reranker**（query↔doc 交互打分），
它与上面这些"对向量空间做无监督变换 / 只按分数重排"**本质不同**：后者拿不到新信息，
前者能读到 (query, chunk) 的交互。**但本机没有缓存 reranker 模型，且代码强制
`HF_HUB_OFFLINE=1`** → 要走这条路必须先下载模型（bge-reranker 系列，0.6–2.3 GB）。

**收益上限提示**：R@16 已 **0.992**，金块几乎总在候选内 → 即使 rerank 完美，
端到端 pass 的增益也有限（此前预测 +0~2pt）；rerank 的主要可见收益在
**gold@1 / NDCG（排序本身）**与"可少塞上下文（top-12→top-6）带来的成本下降"。
