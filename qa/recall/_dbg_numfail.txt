RAW ANSWER:
你问的半自动构建流程对应论文中从 Arabish 转写为阿拉伯字母的增量式半自动标注过程。该流程基于序列神经模型，仅处理从 Arabish 到阿拉伯字母的转写 [2]。具体做法是：先用约 6,000 个人工转写的 token 作为训练与测试数据（10 折交叉验证，9:1 划分），并移除含法语代码转换的整句，使数据缩减至约 5,000 token [2]。模型将 Arabish token 拆分为字符、将阿拉伯语 token 拆分为语素，学习字符到语素的映射，初始 token 级准确率约 71% [2]。随后用该模型自动转写约 5,000 个新增 token（第二标注块），人工纠错耗时约 3 天（纯人工需至少 7.5 天），纠错后的数据加入训练集并继续标注下一块 [2]。当加入第三块数据并标注第四块时，准确率提升至约 80%，此增量流程将持续直至完成全部 25,000 个 token 的标注 [1][2]。
