# 输出闸门「无证据支撑数字」误杀诊断（2026-09-11）

> 起因：2.0 复盘发现 QASPER 233 的 36 道剩余失败里，**10 道是 `validator.gate` 直接兜底**
> （`answer = FALLBACK_MSG`、`cites` 清空），其中 **9 道 gold 明确**。
> 工具：`_gate_probe_qasper.py`（复跑 + 拦截闸门前草稿）＋ `_gate_num_origin.py`（离线溯源，零 LLM）。
> 产物：`GATE_PROBE_QASPER_20260911.md`（逐题判定 + 草稿）、`GATE_NUM_ORIGIN_20260911.md`（数字溯源）。

## 1. 判定结论

**10 道兜底题的闸门触发全部是 `type=number`（0 例 citation）；人工逐条核验后，18 个被报数字
18/18 都是误杀。** 没有一例抓到真编数。

| 自动分桶 | 数 | 说明 |
|---|---|---|
| B 原文确有、归一化后丢失 | **13** | 解析把原文数字弄坏 → 核心问题 |
| C 可由草稿数字推得（豁免②不覆盖） | **2** | 除法＋四舍五入 |
| D 自动判"找不到" | **3** | 人工复核**也全是误杀**：`1700`/`6.67`（操作数被年份规则删掉）、`100`（中文"百"误解析） |

**量级**：9 道有答案题白白变成 `score=1` → 直接损失 **9/233 = 3.9pt**；修复后上限 **82.8% → 86.7%**。

## 2. 五个根因（全部有原文证据）

### 根因① 单位后缀吞掉后一个单词的首字母（3 数）
`numbers.py` 的 `scan_numbers` 把紧跟数字的**单词首字母**当成 SI 单位（K/M/B）：

| 题 | 原文 | 解析结果 |
|---|---|---|
| 1909.00338 | `the top 15,000 most frequent ones` | `('15,000 m', 1.5e10)` ← `m`ost |
| 2003.04967 | `Python 2.7 kernels to code` | `('2.7 k', 2700)` ← `k`ernels |
| 1809.01060 | `Pearson correlation of 0.81 between` | `('0.81 b', 8.1e8)` ← `b`etween |

→ 答案侧写「15,000 个特征」= 15000，证据侧被解析成 1.5e10，**两侧永远对不上**。
（docstring 里记过 `w` 的词界修复，但 `K/M/B` 没做同样保护。）

### 根因② LaTeX 科学计数法未归一（4 数）
QASPER 文本源里公式是 **LaTeX 源码残留**，`scan_numbers` 拆成三个独立数字、合成不了：

| 题 | 原文 |
|---|---|
| 1901.11117 | `a search space of $7.30 * 10^{115}$ models`（注意是 `*` 不是 `\times`） |
| 2001.07209 ×2 题 | `a corpus of $8.5 \\times 10^{11}$ tokens` |

→ 答案侧写 `7.30 × 10^115` = 7.3e115，证据侧只有 `7.30 / 10 / 115`。

### 根因③ LaTeX 转义百分号（5 数）
| 题 | 原文 |
|---|---|
| 2004.03925 | `around 54$\$ tweets are neutral, 29$\$ positive and a mere 15$\$ is negative` |

→ `54$\%$` 里 `%` 被 `$…$` 包裹，解析出裸 `54` **不满足显著判据**（无 `%`、无小数点、<100）→ 直接从证据集合消失。

### 根因④ 年份剥离规则吃掉数据值（2 数 + 1 个操作数）
`_YEAR_RE = (?:19|20)\d{2}` 在归一化前无条件 `sub("")`：

```
"Switchboard-2000 contains 2000 hours"  →  _canonical_nums = []     ← 两个 2000 都被删
```

→ gold 与答案都是 `1700 = 2000 − 300`（差值），但操作数 `2000` 被删 → **豁免② 无法识别**
→ `1700`、`6.67`(=2000÷300) 双双被报。

### 根因⑤ 豁免② 只覆盖差/和（2 数）+ 中文数词词界（1 数）
- `293 ÷ 4262 ≈ 0.069`（答案还写了"约 0.07"）：**除法不豁免**，且 `rel_tol=1e-3` 容不下四舍五入。
- `F1 个 F1 百分点` 里的 **「百」** 被中文数词解析器当成 ×100 → 草稿被提取出一个**并不存在的 `100`**。

## 3. 修复方案（按性价比）

| # | 改哪 | 改什么 | 覆盖 |
|---|---|---|---|
| 1 | `components/numbers.py` | **单位后缀加词界**：后缀后须非字母（`15,000 most` 不再吃 `m`） | 3 数，**最高性价比** |
| 2 | `components/numbers.py` | **解析前做 LaTeX 归一**：`\times`/`*`→×、`10^{n}`→`e n`、`\%`→`%`；或直接识别 `数 × 10^幂` 形态 | 9 数 |
| 3 | `components/validator.py` | **收紧年份剥离**：仅当数字在句中充当年份（如 `in 2000,` / `(2000)`）才删；`Switchboard-2000`、`2000 hours` 保留 | 2 数 + 1 操作数 |
| 4 | `components/validator.py` | **扩展豁免②**：纳入乘/除，并对四舍五入给容差（如 rel_tol 5%） | 2 数 |
| 5 | `components/numbers.py` | **中文数词词界**：`百分点` 里的「百」不应触发 ×100 | 1 数 |

## 6. 修复与验证（2026-09-11 完成）

**改动原则**（用户提出并固化）：**封闭语法用规则一次写死；开放语义不裁决**。
因此单位**成员表刻意不扩充**（`4W` 到底是瓦特还是 4 万，任何枚举都会错）——
归一化层只修"长什么样"，开放词表留给上层复核。

| 文件 | 改动 | 治谁 |
|---|---|---|
| `components/numbers.py` | ① **单位吸附加两侧词界**：左（数字前是 ASCII 字母则不吸附 → `F1 百分点` 不再造出 100）；右（单位后紧跟 ASCII 字母则不算单位 → `15,000 most` 不再 ×1e6、`2.7 kernels` 不再 ×1e3、`0.81 between` 不再 ×1e9） | 根因①⑤ |
| 同上 | ② **LaTeX 语法识别**（属**封闭语法**）：科学计数接受 `\times`/`\cdot`/`{…}` 包裹；百分号接受 `$\%$` 包裹 | 根因②③ |
| 同上 | ③ **「百分」不是量词**（中文单位后紧跟「分」时不吸附） | 根因⑤同类 |
| `components/validator.py` | ④ **年份只在明确语境剥离**（前有 in/since/during/until/from/by/year/©，或后接 年/年代） | 根因④ |
| 同上 | ⑤ **豁免②扩展到四则运算 + 5% 四舍五入容差**（除法/乘法与 `0.0687→0.069` 曾被误杀） | 根因④算式侧 |
| 同上 | ⑥ **派生操作数不再被题干数扣掉**（`Switchboard-2000 − Switchboard-300` 的操作数曾被 `q_sig` 一并剔除，豁免失效） | 复跑时新发现 |

**验证（六项全绿）**：

| 项 | 结果 |
|---|---|
| 数字回归集（28 例：真实误杀 + 边界写法） | **28/28 PASS**（`_num_regression.py` → `NUM_REGRESSION_20260911.md`） |
| 闸门 10 题复跑 | **10/10 兜底 → 0/10**（`GATE_PROBE_AFTER_FIX.md`） |
| 10 题按真实裁判重跑 | pass **0/10 → 7/10**，均分 **1.00 → 4.20**，翻正 10 / 变差 0 → 折算 **+3.0pt**（`GATE_FIX_VERIFY_20260911.md`） |
| **红线**·MinerU hard 30（别回退） | **30/30**（首跑 28/30：1 道经定向复跑确认 LLM 波动 → 4 分；1 道经 gold 逐项对照确认**裁判误判**，答案四项数字与 gold 全等） |
| **红线**·防幻觉负向组 20（别放过编造） | **20/20**（编造 0 / 误断言 0 / 待人工 0） |
| `run_bench` 静态护栏 | 与基线一致，无变化 |

**已知残留（交招1 裁决）**：三操作数派生（`293×15÷4262 ≈ 1.03`）不在豁免② 的成对覆盖内，
且其中一个操作数（15）因"不显著"未进集合 —— 这类**不该再靠扩豁免规则**，应由复核裁决。

**附带发现**：裁判（glm-4-flash）在数值逐项对照上**会误判** —— `mh-30333-q1` 的
DC 四项数字（283,047 / 910 / 9.8 / 1,214）与 gold **全等**，仍被判"不符"。
→ 评测结论遇单题翻车时，**先做 gold 逐项核对**再归因。

## 7. 招1：机器「判定」降级为「提示」（2026-09-11 接上）

**动机**：§6 治的是**可预见**的写法歧义；但"机器没匹配上 ≠ 论文没有"这个结构问题还在 ——
只要有 parser 覆盖不到的新写法（`4W`、三操作数派生、没见过的 LaTeX 变体）就会重现误杀。
招1 把这一类**最终裁决权从机器交给 LLM**（在真实上下文里判）。

**分层（沿用 §5.5 既有原则）**：

| 层 | 职责 |
|---|---|
| 机器（0 成本、确定性） | **高召回**圈出"被引证据与全篇都匹配不到"的显著数字 → `unverified`（**信号，不是结论**） |
| LLM 裁决 | `repairer.adjudicate_numbers` 判"是否支持"：支持 → 放行；不支持/复核异常 → 才升 high，走既有 repair→兜底 |

**改动**：`validate_numbers` 返回 `(hard_issues, supplements, unverified)`；`_machine_checks` /
`check` 增 `adjudicate` 开关（**关时保持旧行为**，供修复回路内复检用严格口径）；
`gate` 增 `adjudicate` 回调与裁决分支；`repairer.adjudicate_numbers` 新函数；`graph.ask` 接线。

**验证（六项全绿）**：

| 项 | 结果 |
|---|---|
| 闸门单测（11 例，含两条新裁决用例） | **ALL PASS**（判支持→pass、判不支持→fallback） |
| 数字回归集 28 例 | 28/28 |
| 闸门 10 题复跑 | **10/10 pass，裁决零触发**（归一化层已消灭误杀 → 招1 未动用，`calls` 与修复前一致 = 31） |
| 🔴 防幻觉负向组 20 | **20/20**（OK 12 + OK-REFUSE 8；编造 0）←「放宽不能放过编造」红线 |
| MinerU hard 30 | **29/30、均分 4.77（历史最高）**，`pass 28 / repaired 2`；唯一失败是波动题 `mh-27843-q2`（评分 3/4/3 摇摆，裁判理由为"未引用 Table 3/Figure 9"） |
| `run_bench` | 与基线一致，无变化 |

**成本**：裁决只在 `unverified` 非空时触发（本轮 10 题 **0 次**；QASPER 233 里 10 次量级），
复核异常**保守判"不支持"**（宁缺毋编）。

**结论**：**招2 治可预见的、招1 兜不可预见的** —— 两层叠加后本类误杀既不复发、也不额外花钱。
