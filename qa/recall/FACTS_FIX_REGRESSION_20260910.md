## 决策记录（2026-09-10）

### 修复 1.1（空清单不注入"未提取到任何候选事实"）→ 实现 → 实测 → **回滚**

| 阶段 | 结果 |
|---|---|
| 实现后 100 题配对回归 | all 71% → **66%（−5）**；`facts=0` 的 4 题 **4/4 全部下降**（其中 3 题 L0——第 1 步根本不跑、纯属被误注入）|
| 归因闸门 | `facts>0` 的 7 题 prompt **逐字未变** → 纯噪声（含 1 例 5→1 的 gate fallback）；`facts=0` 的 4 题同向下降 → 可归因于 1.1 |
| 反因（关键）| 空清单块的**使用规则 c)「禁止因'清单之外没有别的'就断言信息不足」是一条起作用的反拒答护栏**；删整块 = 连护栏一起删，其价值盖过了那句负向提示的危害 |
| 处置 | **回滚**。回滚后 3 题 L0 回到基线（4→4 / 4→5 / 4→4），全局回到 70% vs 71%（**−1，噪声内**）|

> 结论：负向提示确实是瑕疵，但**不能靠删整块来修**。将来若要动，须"只换那一句、保留规则 c)""，
> 并跑 100 题配对回归验证（效应量本身在噪声量级，小样本判不了）。

### 修复 1.2（JSON 宽松解析兜底）→ **保留**

- 性质：严格解析成功时行为**完全不变**；仅在失败时把"整份丢弃"改为"按条目抢救"——**超集，无副作用**。
- 实证：`3de27c81` 从 0 条 → **13 条**，捞回 gold 数值 `421,829,960 words / 17,305,401 sentences`。
- 本轮 100 题未观察到可归因收益（受影响题仅 ~2.5%，效应在噪声量级）——
  **保留理由是"不再丢数据"，不是"提分"。**

### 副产品发现：链路有两类不确定抖动

1. **路由档位会变**：同题同配置两次运行，`3bfb8c12f1` 一次走 L0、一次走 L3。
2. **gate 结果会变**：`66f0dee89f` 同 prompt 两次运行 5→1（`action=fallback`）。
→ 回归判读必须**以"prompt 是否变化"为归因闸门**，否则会把噪声当成 bug。

### 最终净变更

`src/paperpilot/agents/nodes/answer.py` **只保留 1.2**（新增 `_salvage_facts` / `_normalize_facts`，
`_extract_facts` 改走原始文本 + 宽松兜底）；`_fmt_facts_block` 回滚原样（docstring 已记录本次实验与结论）。
