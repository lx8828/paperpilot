## 6. 本轮暴露的关键认知

### 6.1 v2 改造让 chunk 向量缓存全量失效（一次性成本，也是重要发现）

`ChunkIndex` 签名随切分/`ordered_chunks` 变化 → **旧 `cvec.npy` 全部作废**，两把尺子首次跑都在**逐篇重编码**（实测 ~45s/篇）。

**双重意义**：
- **代价**：④⑤ 从"几十秒"变成"2.5 h + 1 h"（0 元，纯本地）。
- **价值**：**此前所有召回类数字都是在旧切分的向量上算的**。这一次才真正把尺子校准到 2.0 口径，
  并且结果（R@12 0.984 / 定位 250/250）**证明切分改动没有造成召回回归**。
- **教训**：向量缓存必须有**显式失效策略**（记录切分器版本/签名），否则"缓存命中"会让评测**静默地测旧系统**——
  与阶段 N 里"figures 回归被缓存掩盖两个月"是**同一类陷阱**。

### 6.2 输出闸门是当前最大的单点损失（可定向收敛）

- MinerU hard：闸门判定 `repaired 1` → **净收益**（5 分）。
- QASPER 233：**10/40 失败来自闸门兜底**（4.3pt）→ 参照 §5.7 的两类误杀，其中一部分**疑似误杀**。
- 方向：把闸门在 QASPER 上的 10 个 fallback 逐条 dump（像 `_gate_probe.py` 那样打印完整判定），
  区分"真拦住幻觉"vs"误杀"；只对前者保留。**零结构改动，预期低成本回收。**

### 6.3 排序精度是真实的、但不属于切分的短板

全对平均余弦 **0.605**（高基线/各向异性）+ margin>0 仅 **28.9%** + gold↔最近非 gold (0.511) > gold 自身 (0.479)。
→ 由 §4.2-C 可知**换切分无法改善**（5 种策略 AUC 全在 0.66–0.71）→ 归因于 **retriever 对长科学问句的打分能力**，
不该记在切分头上。可选方向：各向异性校正（去中心化/白化）、rerank、查询改写（此前 A/B 为负收益，已默认关）。

### 6.4 诚实性责任的转移

`unknown_ok 48 → 0`：漏斗不再产出拒答桶，"不够就诚实说不知道"的守门职责**转移到输出闸门**。
→ 负向组（§2）从"补充验证"升级为**必须常跑的守门测试**。

### 6.5 无答案题诚实拒答退化的根因（已定位：`nol3j` 默认开启）

**现象**：无答案题（gold 空，21 题）诚实拒答认可率 **95.2% → 66.7%**（V2 20/21 → 2.0 14/21），
逐题 diff 后 **6 题翻黑 + 1 题（真实无答案题 `2001.07209`）两轮都 fail**。

**机制（代码级证据）**：

| 环节 | 事实 | 出处 |
|---|---|---|
| 默认图 | `graph.ask` **默认走 `nol3j` 变体**（`os.environ.get("PAPERPILOT_V3_NOL3J","1") != "0"`） | `graph/qa_graph_v3.py:112` |
| 该变体 | **删掉 `judge_l3`**，`search_l3 → answer` 一律试答 | `qa_graph_v3.py:76-100` |
| **后果** | **`answer_unknown` 节点保留但图内无入口** | `qa_graph_v3.py:83`、`agents/nodes/__init__.py:12` |
| 所以 | `unknown_ok ≡ 0` 是**构造性的**，不是概率问题 | — |
| 换来的收益 | `ab_nol3j`（100 题同裁判）：hard 19/50→29/50（**+10pt**）、合计 64%→73% | `qa_graph_v3.py:107` |

**为什么这个设计会伤到无答案题**：删 `judge_l3` 的动机是"证据里有答案却被判不够 → 白拒答"（误杀成本）。
删掉后 quality 交给输出闸门 —— **但闸门只做事实校验（数字/引用越界），不判断"这个问题论文本身没有答案"**，
于是这一类**没有任何一层兜底**。

**逐题看，退化的形式高度一致**（6 题里有 6 题是 score=3，差 1 分即 pass）：

| | 答案形态 | 裁判 |
|---|---|---|
| V2 | `抱歉，我无法从该论文中找到…（论文中并未讨论…）` → 首句即明确拒答 | **5** |
| 2.0 | `你问的 X 对应论文中…（给出相关事实+引用）…但证据并未具体说明 Y` | **3**（"部分正确，遗漏关键信息"） |

典型例（fastText 评测数据集题）：
- V2：`抱歉，我无法从该论文中找到用于评估的具体数据集名称，因为检索到的内容未提及…` → 5
- 2.0：`你问的评测数据集对应论文中 fastText 的评测任务。论文在 tag prediction 和 sentiment analysis 两个任务上评测了 fastText [1]。但…未列出具体数据集名称` → 3
- 裁判：`系统正确地指出了论文中未提供具体数据集名称，但引用的论文原文并未直接支持其关于数据集的说明`

**判读（两条都要认）**：
1. **一半是"格式税"**：新答案其实**信息更多**（给了相关事实 + 顺带说明没直接给），只是**不再首句显式拒答**，
   而 QASPER 的无答案题评分明确奖励"诚实说明没有"。差 1 分（3 vs 4）几乎全在这个格式差上。
2. **一半是真问题**：部分答案把"相关但不等价的内容"当成了答案主体（如把"评测任务"当成"评测数据集"），
   对"帮读器"定位来说这是**过度承诺**，不是好的产品行为。

**处置（2026-09-11 决定）**：

1. **改口径，不判低**：系统"给相关片段让用户自行判断"**体验明显更好**，产品口径为合格 →
   新增 `excerpt_ok` 桶（不计 fail）→ 无答案题合格率 **66.7% → 85.7%**，与 V2 差距收到 −9.5pt。
   剩余 3 题为真 fail。
2. **`nol3j` 不回退**：它换来的 hard +10pt 是真的；`answer_unknown` 无入口是**已知取舍**，不是 bug。
3. **系统职责边界不动**：本系统**不做"用大模型自身知识补答"**（见 §6.6）。

> **订正（2026-09-11 上午，闸门修复后复跑）**：本节"退化"的说法**已不成立**，两点更正：
> ① **量级**：闸门误杀修复后（§9#2），同样 21 题的无答案桶合格率 **85.7% → 95.2%（20/21，pass 17 + `excerpt_ok` 3）**，
> **与 V2 的 20/21 完全持平 → 无退化**。无偏样本 500 题上合格 **43/52 = 82.7%**，真没过 9 题。
> ② **性质**：剩余 10 题（233 1 + 500 9）逐条看，裁判措辞**全是"回答正确 / 正确指出了 X，但完整性或证据直接性不够"**
> （3 分档），**无编造、无答非所问**；且这些题 gold 为空、系统却能找到相关原文 → 疑似 **QASPER `unanswerable` 标注噪声**。
>
> → 故本节"修复方向"（改 SYSTEM 加无答案收尾准则）**不必实施**；
> 判据与复算工具：`cli/run_qasper_eval.py`（`_absence_tone`）+ `qa/recall/_rescore_unans.py`。
> 详见 `qa/REPORT_NIGHT_20260911.md` §③④。

### 6.6 架构决策：外部知识补答**不放在本系统**，留给外层的 agent

**决策**：论文确实没有答案时，本系统**只负责**返回两样东西——
**① "论文未提供该信息"的明确结论 ② 检索到的相关原文片段**；**不调用模型自身知识补答**。

**分工（将来）**：把 PaperPilot 做成 **MCP 工具**后，由**外层 agent（其 LLM）**补答——
工具返回"不知道 + 相关片段"，外层 LLM 结合自身知识作答，并由**外层**负责告诉用户
"这段不是论文内容，请自行分辨"。

**为什么这样切**：
- 本系统最值钱的能力是**溯源闭环**（§0 核心信条："所有结论必须能回到原文"）。一旦允许它用
  模型知识作答，`cite` 体系与 `validator` 闸门（无据数字/引用越界 → HIGH）就**自相矛盾**，
  最硬的差异点被稀释。
- 补答是**模型能力**问题、不是检索问题；放在**调用方**做，可按调用方自己的合规/免责策略
  决定"补不补、怎么标注"，不必绑死在本工具里。
- 接口更干净：工具保持**确定性、可验证**，不确定性上浮到 agent 层。

> **推论**：评测口径必须能容纳"本系统返回不知道"是**正确行为**——这正是 `excerpt_ok` /
> `honest_refuse` 桶存在的意义，也是负向组（§2）必须常跑的原因。
