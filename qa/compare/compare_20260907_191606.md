## 4. 结论与解读（人工）

**总体**：三列同批 64 题、同裁判盲判：B2 PaperPilot pass 51/64（80.4%@有答案题）> B1 朴素 RAG 49/64 > B0 直接 LLM 46/64；均分 4.17 vs 3.89 / 3.86。

**但优势幅度比预期小、且结构分布很关键**：
1. **B1 朴素 RAG 很强**——extractive 36/39 反超 B2 的 35/39。本批近半是"某数据集/指标/实验任务"这类局部定位题，top-12 纯向量已足够，B2 的 363 次调用没换来这类题优势。**差异点不在"普通检索能答的题"，别拿这类题讲故事。**
2. **B2 的优势集中在三处**（正是 B0/B1 的结构性弱点）：无答案题诚实拒答被认可 6/8 > 5/8 > 4/8；平均 cites 1.91/题（唯一有证据引用的一列，裁判明示"引用不实降分"）；均分高出 0.3（同样判 pass，B2 的答案更全、更少"踩点但漏细节"）。
3. **B0 直接 LLM 没有 overflow**（20 篇全文估算 ≤ 12K token，全部塞得下）——"放不下"优势在此样本未触发；B0 的代价体现在 token：334K（≈1.35× B1），且它 free_form 反而最好（7/13，靠全文全局视野）。
4. **成本/延迟画像**：B2 生成 token 726K ≈ 2.9× B1、调用 363 ≈ 5.7×，单题作答 6.6s vs 1.4s；但绝对成本仍很小（估 ¥1.64/64 题 ≈ ¥0.026/题）。**"更贵更慢"要这样讲：贵 3 倍，绝对值是一道题 2.6 分钱；换来拒答可靠与证据可溯源。**

**局限**：n=64 太小，B2-B1=+2 在统计上不显著；裁判是 glm-4-flash（免费档，判定偏松或偏紧皆可能，三列同口径只比相对）。要对外宣称"我们比朴素 RAG 强"，需扩到 250+ 题或加同题复跑；本次价值是**画像**而非定论。

**一句话**：PaperPilot 不是"普通问题答得更准"的系统，是"该拒答时诚实拒答 + 每个答案带真实证据 + 难题能下钻"的系统；朴素 RAG 在简单定位题上已接近上限——下一轮对比若只放难题/无答案题/跨节合成题，B2 的差距才会拉开。
