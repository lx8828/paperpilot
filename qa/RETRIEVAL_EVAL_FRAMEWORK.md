## 4. 使用规则

1. **v3 日常改动**：跑 T（同口径 QASPER pass + 相关专项切片）+ 回归护栏 + E 成本 diff；"pass 不降 + 成本不涨"即过。
2. **提默认 / 对外宣称**：必须 A——同题同裁判 + 显著性（n 小明确标注"画像非定论"），引用数字带口径。
3. **C 层（Recall@k/MRR）单篇不建**：等「多篇/大语量 + 加 rerank/query 理解/上下文压缩」时再立（评判台已在框架预留）。MinerU 前后各跑一次 T 当接入对照。
4. 所有 run 落 `qa/*_result.json` + seed 固定（可复现）；结论进 `DEVELOPMENT_LOG`。
