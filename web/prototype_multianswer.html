🧭 方向检索 现有
给一个研究方向 → 检索并下载论文 → 解析建索引 → 出结构化报告，并在这些论文上问答。
产物：一篇论文的深度报告
大模型长上下文的高效注意力 表格问答的检索增强
🎯 多答案开放域检索 新增
给一个问题 → 在已有论文语料里检索 → 逐篇判定"这篇做没做这件事" → 给出符合的论文清单（每篇带证据片段）。
产物：哪几篇论文符合（多答案）
语料规模 N
20 50 100 300
← 选「从多少篇里找」，不是「答案条数」
★ N 的两处代价：建索引与 N 成正比（首次约 3 秒/篇，之后走缓存）； 逐篇判定只与"被判定篇数"成正比。N 越大检索越必要，但题均成本越高。
